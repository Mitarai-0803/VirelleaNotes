詳解

増水パズル用の静的な足場オブジェクト

FloorObject と似た構造だが、複数同時に設置されることを前提に 「天面のワールドY座標」を取得する GetTopY() を持つ点が異なる。 水位と比較して足場が水没したかどうかを外部から判定できるようにする。

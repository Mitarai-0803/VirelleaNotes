詳解

物理演算ボックスオブジェクト

BoxCollider を持ち Jolt 物理シミュレーションで動作する。 SetPlayerControlled(true) を呼ぶと、矢印キー / WASD キーでの XZ移動・スペースキーでジャンプができる「プレイヤー操作モード」になる。

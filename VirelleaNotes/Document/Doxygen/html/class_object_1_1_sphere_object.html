詳解

物理演算球オブジェクト

SphereCollider を持ち Jolt 物理シミュレーションで動作する。 コンストラクタはスポーン座標と半径の保存のみを行い、 コライダーの生成・登録は OnInit() で行う。 座標／回転は基底クラス ObjectBase3D::GetPosition() 等が 自動でコライダーへ委譲するため、本クラスで二重管理はしない。

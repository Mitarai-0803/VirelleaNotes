詳解

波紋シミュレーションを行う水面オブジェクト

  • コンストラクタは引数を保存するだけに留め、 実際のバッファ確保や初期波生成は OnInit() で行う
  • グリッド状の高さバッファ(現在・前・次フレーム)を使い 有限差分法で波の伝播を毎フレーム更新する
  • 描画用の頂点バッファも OnInit() で一度だけ確保し、 OnDraw() では値の書き換えのみ行う（毎フレームのヒープ確保を避けるため）
  • DXLib の TriangleStrip でグリッドをリアルタイム描画する
  • ObjectBase3D を継承し、シーンのオブジェクトリストで ライフサイクル管理(Init / Update / Draw / End)される
  • 外部から状態を変更する場合は必ず Set 系メソッドを使用し、 メンバ変数への直接アクセスは行わない（カプセル化を維持する）

\doxysubsection{詳解}
物理演算球オブジェクト 

\doxylink{class_sphere_collider}{Sphere\+Collider} を持ち Jolt 物理シミュレーションで動作する。 コンストラクタはスポーン座標と半径の保存のみを行い、 コライダーの生成・登録は \doxylink{class_object_1_1_sphere_object_a994635364937413dc37cf5f2e03de07a}{On\+Init()} で行う。 座標／回転は基底クラス Object\+Base3\+D\+::\+Get\+Position() 等が 自動でコライダーへ委譲するため、本クラスで二重管理はしない。

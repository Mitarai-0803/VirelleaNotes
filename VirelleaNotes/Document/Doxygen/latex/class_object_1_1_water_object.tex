\doxysubsection{詳解}
波紋シミュレーションを行う水面オブジェクト 


\begin{DoxyItemize}
\item コンストラクタは引数を保存するだけに留め、 実際のバッファ確保や初期波生成は \doxylink{class_object_1_1_water_object_a9fa6dcf14538f81833138290c4a2b05d}{On\+Init()} で行う
\item グリッド状の高さバッファ(現在・前・次フレーム)を使い 有限差分法で波の伝播を毎フレーム更新する
\item 描画用の頂点バッファも \doxylink{class_object_1_1_water_object_a9fa6dcf14538f81833138290c4a2b05d}{On\+Init()} で一度だけ確保し、 \doxylink{class_object_1_1_water_object_a59cf25769549d5744da6526ca79d9b86}{On\+Draw()} では値の書き換えのみ行う（毎フレームのヒープ確保を避けるため）
\item DXLib の Triangle\+Strip でグリッドをリアルタイム描画する
\item \doxylink{class_object_1_1_object_base3_d}{Object\+Base3D} を継承し、シーンのオブジェクトリストで ライフサイクル管理(Init / Update / Draw / End)される
\item 外部から状態を変更する場合は必ず Set 系メソッドを使用し、 メンバ変数への直接アクセスは行わない（カプセル化を維持する） 
\end{DoxyItemize}

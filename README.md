# VirelleaNotes

> 自作のシンプルな音楽ゲーム

自作の音楽ゲームです。もう一つの譜面作成エンジンを使うことで、譜面データを作成し、そのデータを読み込み遊ぶことができます。
※まだまだリファクタリングとバグの除去・調整など課題はありますが、現状遊ぶことはできます。

## 特徴

- 自作の譜面作成エンジンのデータを読み込み遊べる。

## 使用技術

- C++
- 外部ライブラリ(詳しくは[ReoEngine](https://github.com/Mitarai-0803/ReoEngine)を確認してください)

## インストール

```bash
プロジェクトファイルをクローンして、VirelleaNotes/Open.cmdを開き実行・ビルドしてください。
※exe用のブランチも追加予定です。
```
